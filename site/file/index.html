The actual problem

You can't tell if you're invisible or just not good enough.

Those two need opposite fixes. If recruiters are seeing you and passing, you need a stronger case. If they were never shown you at all, your case is irrelevant — nobody read it.

Right now you have no way to tell which one you're living. So you do the only thing available: apply to more things. Which, if the second one is true, changes nothing.

Why the search is the thing to measure

LinkedIn's own published research says its recruiter ranking is trained to predict whether a candidate will reply to a message — not whether they're the best fit. Two equally qualified people don't rank equally.

Sources: LinkedIn Talent Search papers, SIGIR 2018 · CIKM 2018 · WWW 2019, and an independent AAAI 2026 audit. I don't use figures I can't trace.

The method

You don't have to trust me. You can check me.

Every File publishes the full query — the exact filters, the tier, the date, the result count. Run it yourself if you want to. A published query can be checked; a claim can only be believed.

Run manually, in a paid seat. No scraping, no bots, no extraction tools. A person builds the search and runs it, at your request.

Scope is always declared. Search tiers see different slices of LinkedIn. Yours states which tier ran it. If you fall outside that tier's reach, you're reported as out of scope — never as absent.

One filter at a time. Filters come off one by one until you appear. The first removal that admits you is the thing excluding you. That's a cause, not a guess.

What this doesn't claim. It measures whether you get found. Not whether you get hired. Anyone promising the second from a profile edit is selling you something.
