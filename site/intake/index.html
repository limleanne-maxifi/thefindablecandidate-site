While you wait, one thing worth knowing: a recruiter's search returns exact matches. It doesn't read your profile and judge it — it matches strings against fields, then stops. Most people who never come up aren't underqualified. They're missing a word.

The method

You don't have to trust me. You can check me.

Every file publishes the full query — the exact filters, the tier, the date, the result count. Run it yourself if you want to. A published query can be checked; a claim can only be believed.

Run manually, in a paid seat

No scraping, no bots, no extraction tools. A person builds the search and runs it, on screen recording, at your request.

Scope is always declared

Search tiers see different slices of LinkedIn. Yours states which tier ran it. If you fall outside that tier's reach, you're reported as out of scope — never as absent.

One filter at a time

Filters come off one by one until you appear. The first removal that admits you is the thing excluding you. That's a cause, not a guess.

What this doesn't claim

It measures whether you get found. Not whether you get hired. Anyone promising the second from a profile edit is selling you something.
